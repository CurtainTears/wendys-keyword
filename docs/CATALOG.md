## 可追溯的公开来源

- 数据：[skywind3000/ECDICT](https://github.com/skywind3000/ECDICT)。英文词条、中文释义、考试标签与词频字段来自该项目。
- 固定版本：[ab22ad36302cafc6349a050e2b60894855208055](https://github.com/skywind3000/ECDICT/tree/ab22ad36302cafc6349a050e2b60894855208055)，提交日期 2026-10-24。
- 原始文件：该版本的 `ecdict.csv`，770,611 行数据。
- 许可证：MIT，Copyright (c) 2025 Linwei；完整授权说明保存在 [ECDICT-MIT.txt](../licenses/ECDICT-MIT.txt)。

每本词库的详情页可查看收录条件、固定版本和授权说明。复制、编辑以及 JSON／CSV／TXT 导出会保留来源说明；CSV 的 `source` 列和 TXT 的 `## keyword-source:` 注释用于往返这些信息。

## 适合学习的中文释义

- 保留目标词的原始拼写，不为了适配打字而删除字母、数字或符号。
- 将源数据的换行和回车转义恢复为正常文本。
- 有通用义项时，省去单独标注的计算机、医学等专业领域释义行；只有专业义项时保留其释义。
- 对 `a`、`the`、`be` 等 10 个基础词使用人工校订释义，清单见 [meaning-overrides.json](../seed/meaning-overrides.json)。
- 所有收录词条都有中文释义，生成时检查完整标签数量、词条标识和打字字符兼容性。词库内容会保留多义信息，不按第一个义项截断。

## 维护与同步

```bash
npm run catalog:build
```

生成器使用固定的上游版本；首次下载到被 Git 忽略的 `.cache/ecdict/`，后续复用缓存。输出为 `seed/decks.json`、`seed/catalog.json` 和许可证文件。升级上游版本时需明确调整生成器的版本、清单发布号和预期词数，再执行检查。

应用启动时，在同一个数据库事务里同步新的内置词库版本、下架指定示例并记录发布号。已有数据库不需要重建。私人词库、账号和学习记录不参与内置词库替换；已下架词库的历史快照继续供旧记录和正在结束的练习使用。
