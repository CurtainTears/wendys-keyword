# 关闭页面，下次接着练

在词库卡片点击“继续练习”，或在“打字练习 → 上次练到这里”选择一轮。已输入的字母、错词、连击和有效用时会恢复；离开页面的时间不计入，恢复后等第一个按键再开始计时。

默认“全部词库”展示系统内置与自己的词库。登录后的所有账号看到同一套系统内置词库，个人词库、遍数进度、续练断点与错词状态各自独立。

## 整本词库按组推进

- 一遍开始时打乱词条顺序，之后按这个顺序分组，每轮最多 30 个不同拼写。
- 本遍已练过的词条不会被下一组重新抽中。相同拼写的不同义项延期到后续组，不会因轮内去重而遗漏。
- “已练”包含完成和跳过；跳过仍进入错词本，不代表已掌握。卡片同时显示跳过数量。
- 整遍走完后显示“开始下一遍”，点击才重新洗牌。
- “重新开始”需要明确确认：本轮计时、连击重新开始；整库已练进度与错词历史保留，旧断点归档。
- 词库发生编辑时，未完成的一轮继续用原快照；下一组接入最新词库，未修改词条的进度保留，新增或改了内容的词条重新进入队列。

## 我的错词会逐渐变少

输入出错或跳过，会立即在当前账号的动态错词本留下状态。同词同义合并来源，大小写和常见引号／连字符规范化后比较拼写，释义按规范化后的文本精确匹配；不猜测两个不同释义是否同义。多义词分开保存。

- 每轮对同一词只计一次“出错轮数”，连续按错多个键不会冒充多轮常错。
- 同一次先错后补打正确，不算无错通过。
- 连续两次独立练习都零错完成，自动移到“已掌握”；再次出错会返回待复习。
- 可以手动点击“已掌握 · 移出”，也可以在“已掌握”恢复复习。归档不删除词条、来源或历史记录。
- 原来的“本轮易错词”和“重练错词”保留，重练会建立独立轮次并参与错词状态更新。
- 首次升级会从已有完整练习记录回填错词及词条覆盖信息；旧版本没有保存的半轮无法回填。

## 本机保存与跨设备接续

每次输入先更新本机断点，账号端约每秒合并上传；不在按键路径等待网络。断点缓存明确绑定账号；未登录不开放词库或练习，旧版访客 IndexedDB 保留用于迁移。

换设备时，先在原设备确认同步状态，再在新设备登录同一账号并继续对应轮次。接续会更新写入代次，旧设备不能覆盖新进度。它再次连接后会提示冲突，并提供：

1. **载入最新进度**：确认后使用服务端断点。
2. **另存本机这一轮**：把离线输入保留为独立练习，不影响另一设备；已经共享的词条前缀不重复增加无错次数。

即使另一设备已经完成原轮次，未上传的本机副本也会在“上次练到这里”继续显示。未上传的数据只能先在原设备找回。

手动标记也会排队同步。若另一设备已产生新练习结果，旧标记不会强行覆盖；页面显示未执行原因，可按最新状态重新操作，或清除未执行的标记。

本机存储失败时会保留当前页面内存副本并提示重试／导出，此时不要强制关闭页面。清除浏览器数据会删除尚未上传的断点，不能作为解决同步问题的方式。

## 保存的数据与接口

账号数据保存在 SQLite 的 `learning_documents` 中，主键为 `owner_id + kind + id`，由同一事务保存断点、整库进度和错词观察结果。旧版访客 IndexedDB 数据仍保留，不再开放新的访客学习入口。

- 学习队列保存词库版本、遍数、固定顺序、已练与跳过词条。
- 每轮保存至多 30 条规范词条及来源快照、写入代次、单调序号、已练明细、当前输入位置和统计。
- 错词保存按轮去重的观察记录、多个来源及版本化手动操作；迟到结果不按“最后上传覆盖”计算连续无错。
- 已完成的新轮次与旧 `practice_sessions` 共同出现在练习记录。原 `POST /api/sessions` 继续可用，保持旧客户端提交条件。

所有接口使用已有 Cookie 会话和 `X-Keyword-User` 预期账号检查，参数不能指定其他用户的数据归属。

| 接口                                       | 用途                                     |
| ------------------------------------------ | ---------------------------------------- |
| `GET /api/learning`                        | 当前账号的续练入口、各词库进度和错词数量 |
| `GET /api/learning/reviews`                | 当前账号的待复习与已掌握词条             |
| `POST /api/learning/rounds`                | 开始／接续一组，操作标识保证重试幂等     |
| `GET /api/learning/rounds/:id`             | 读取自己的规范轮次快照                   |
| `POST /api/learning/rounds/:id/claim`      | 版本校验后换设备接续                     |
| `POST /api/learning/rounds/:id/checkpoint` | 按代次与单调序号保存，校验词序和统计     |
| `POST /api/learning/rounds/:id/retry`      | 独立重练本轮错词                         |
| `POST /api/learning/rounds/:id/fork`       | 保留本机冲突副本                         |
| `PUT /api/learning/reviews/:id`            | 版本校验后手动移出或恢复                 |

词库页的 JSON 备份包含服务端学习状态及当前账号本机未同步副本，供查阅与应急保留；JSON 导入仍只处理词库。账号和学习状态的完整恢复使用 SQLite 在线备份。

## 验收证据

自动检查覆盖整库 30／30／5 分组、多义词覆盖、词内恢复与暂停计时、代次冲突、事务回滚、离线重开补传、旧响应不覆盖新缓存、账号隔离、历史回填、两次无错及手动归档。

浏览器使用独立测试数据库，实际完成账号断点恢复、两次无错自动归档、账号换设备接续、旧设备离线输入关闭重开、冲突副本另存，以及跨库同词来源合并。测试没有替换正式内置词库。
