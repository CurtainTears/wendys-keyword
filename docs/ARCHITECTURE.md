# 数据与接口

## 数据归属

- `user / session / account / verification / rateLimit`：由 Better Auth 管理。`user.role` 是只允许服务端写入的 `user / admin` 权限字段，旧账号默认 `user`。
- `signup_invitations`：邀请码散列、备注、创建与到期时间、使用时间与邮箱、撤销时间。另含授权角色、创建者、尾号及管理页创建码的 AES-256-GCM 密文。完整码仅供管理员在有效期内查看，不进入用户导出；使用或撤销后删除密文。
- `decks`：稳定 ID、所属用户、名称、说明、版本与回收站状态；内置词库的所属用户为空。
- `words`：所属词库、稳定词条 ID、顺序、原始拼写、释义。同词不同义独立保存。
- `deck_sources`：词库的来源、收录条件、许可证和内置排序；私人副本继续保留原始来源说明。
- `deck_revisions`：词库的不可变版本快照，练习记录始终引用开始练习时的版本。
- `practice_sessions`：每位用户的独立单轮记录，以用户 ID + 练习 ID 幂等写入，统计不会跨轮拼接。
- `import_operations`：按用户保存导入操作结果，网络重试不重复建立词库。
- `legacy_scores`：只读历史匿名榜单，不包含私人账号数据。
- `learning_documents`：按账号存储固定学习队列、带代次的续练断点、完成轮次、按词聚合的错词观察和版本化手动操作。规则与接口见 [学习状态](LEARNING.md)。

SQLite 使用外键、WAL、FULL 同步和事务；事务提交完成才返回成功。读写异常不会替换为空数据。数据和本机密钥在静态目录外，默认不进入 Git。

未登录只开放登录注册界面、认证接口、`/api/me` 和不含业务数据的健康检查，其余 API 统一返回 `401 / LOGIN_REQUIRED`。浏览器 IndexedDB 的 `decks / sessions` 保留旧版访客数据供迁移；`outbox` 记录带有所属账号 ID，仅在该账号登录时发送；`meta` 保存访客迁移的幂等操作与完成状态。`studyMeta / studyCache / studyActions` 保存访客学习状态及带所属账号的断点、待上传副本与手动操作；账号快照不写入访客词库或访客历史。已登录私人词库不写入访客词库缓存。浏览器同一系统用户对开发者工具、磁盘的访问不属于应用级账号隔离。

## 接口

所有修改请求使用 `Content-Type: application/json` 和配置允许的 `Origin`。账号 API 使用 Cookie 会话。前端同时发送 `X-Keyword-User`，服务端发现与实际会话不一致时拒绝，防止其他标签页切换账号后把旧草稿误写到新账号。此校验也适用于前端的注销和修改密码请求。会话续期的 Set-Cookie 会随应用 API 响应返回浏览器。

- `GET /api/health`：数据库可读性检查。
- `/api/auth/*`：Better Auth 邀请码邮箱注册、登录、注销和修改密码。`POST /api/auth/sign-up/email` 的 JSON 必须含有效 `inviteCode`；缺失返回 `403 / INVITE_REQUIRED`，无效、已用、过期或撤销返回 `403 / INVITE_INVALID`。登录和已有账号不要求邀请码。
- `GET /api/me`：当前用户（含服务端权限 `role`）或 `null`。
- `GET /api/catalog`：所有已登录账号共享的内置词库摘要。
- `GET /api/decks`：当前账号有效私人词库；`?trash=1` 为回收站。
- `POST /api/decks`：建立私人词库，内容为 `{ title, description, words, source? }`；`source` 只接受有界纯文本及 HTTPS 来源链接。
- `GET /api/decks/:id`：读取内置或自己的有效私人词库。
- `PUT /api/decks/:id`：用 `{ version, title, description, words }` 整体保存。版本不一致返回 `409`，不写入。
- `DELETE /api/decks/:id`：用 `{ version }` 移入回收站。
- `POST /api/decks/:id/restore`：用 `{ version }` 从回收站恢复。
- `POST /api/decks/import`：`{ decks, operationId? }`；原子地建立 1–30 个词库，可用同一操作标识重试相同请求。
- `GET /api/sessions`：当前账号最近 100 轮练习，合并旧记录与已完成的新学习轮次。
- `POST /api/sessions`：提交一轮练习，包含客户端独立 ID、词库 ID、词库版本、耗时、正确／总按键、完成／跳过词数、最长连击和词条明细。服务端核对归属与版本，并从版本快照取词条和释义。
- `GET /api/export`：当前账号全部词库（含回收站）、全部练习记录和学习状态，不导出登录凭据。
- `GET /api/board?bank=...`、`GET /api/dump`：保留历史匿名榜单查询与旧数据导出，始终不含新账号数据。
- `POST /api/score`：返回 `410`，匿名昵称写榜已停用。新客户端使用 `/api/sessions`。

私人词库对其他已登录用户返回 `404`；未登录的业务操作返回 `401`；会话过期返回 `401 / SESSION_EXPIRED`，预期账号与会话不一致返回 `409 / ACCOUNT_CHANGED`；来源错误返回 `403`；存储失败返回 `500`，不宣告成功。响应携带请求 ID 便于从服务日志定位错误。

## 邀请码与注册事务

管理员页面使用以下接口，每次都从实际会话检查 `user.role === "admin"`，普通账号返回 `403`：

- `GET /api/admin/invitations`：列出状态、备注、有效期、使用邮箱和可用完整码。
- `POST /api/admin/invitations`：接受 `{ days, label }`，只能创建普通用户邀请码，不接受提权参数。
- `POST /api/admin/invitations/:id/revoke`：撤销未使用的邀请码。

本机 `npm run invite -- create --admin` 只用于所有者初始化管理员账号或受控维护，没有网页提权接口。邀请码包含 160 位随机数，默认 7 天有效、一次性使用；大小写、空白和分隔连字符不影响识别。注册用规范化后的 SHA-256 散列校验；管理页创建的邀请码另以 HKDF 派生的 AES-256-GCM 密钥加密，邀请码 ID 作为附加认证数据，不能交换密文冒充另一条记录。恢复显示需要原登录密钥，密钥改变或密文损坏时明确提示无法解密。
Better Auth 的注册前置钩子先验证邀请码，再进入密码计算。用户创建钩子在 SDK 的 SQLite 注册事务内以条件更新占用邀请码，与用户、权限、密码账号和会话一起提交；任何后续失败都会回滚占用。非邮箱注册路径的用户创建同样被拒绝。每分钟 5 次注册限流仍作用于失败请求，客户端转发 IP 不受信任。

Better Auth 的异步事务与应用数据层共用一个 SQLite 连接。API 数据库操作按请求串行执行，避免密码计算期间其他请求开启嵌套事务或参与错误事务。请求体先在有大小和时间限制的接收阶段读完，再进入队列；静态文件不等待数据库队列。

## 同步模型

服务端是账号词库的权威版本。词库及当前练习记录页每 20 秒轮询，窗口重新聚焦、恢复可见或恢复联网时也检查更新。编辑期间仍校验账号，但不自动替换草稿。浏览器同源标签页通过 BroadcastChannel 通知登录状态变化；身份切换会清除旧页面、草稿和搜索条件，并使旧请求失效。保存时检查版本；编辑冲突时可以导出草稿，再明确载入新版本。正在练习的一轮使用不可变快照，下一组接入最新词库并按未变词条保留整库进度。断点先落本机再合并上传；接续采用写入代次与单调序号，旧设备的未同步副本可显式另存，不覆盖新设备。

内置词库按 `seed/catalog.json` 的发布号同步。整批更新与指定示例下架在一个事务内提交，异常时保留原目录；只允许更新无所属用户的内置行。历史版本不改写，私人副本不跟随内置更新。完整来源与维护方式见 [内置词库说明](CATALOG.md)。

练习结果先进入本机账号专属待同步队列；服务端按单轮 ID 幂等落盘。网络失败保留队列，重新联网、重新打开页面或登录原账号时重试。其他账号不读取、不提交此队列；界面回填也绑定账号代次。完成时间来自单轮结果，补传不会改成上传时间；旧客户端省略时间时仍使用接收时间。不可自动解决的校验错误保留本机副本并显示错误，不循环提交；用户可手动重试并导出数据。

访客迁移仅复制选择范围内的访客词库，不移动账号归属、不认领昵称成绩、不删除原件。每批最多 30 本；批次结果幂等，响应丢失后可重试。

## 可迁移性

JSON 和 CSV 是交换格式，不是账号数据库。JSON 词库导入会生成新的词库与词条标识；CSV 的公式保护会影响公式样式文本的逐字往返，应使用 JSON 无损导入。SQLite 在线备份是账号、全部历史版本及练习记录的整站恢复入口。跨主机扩展时应迁移到共享的关系数据库，不复制正在运行的 SQLite 文件充当同步。
